# Sowena SEO Publishing Settings

These settings are the default operating rules for Sowena Beauty Global SEO content.

## Market

- Primary market: Global
- Regional priority: global buyers, clinics, distributors, wholesalers, and beauty partners
- Local time for publishing: Vietnam time, UTC+7

## Language

- Article language: English
- Tone: premium, practical, trustworthy, modern, and easy to understand
- Reader level: professional buyer, not casual consumer

## Product priority

Prioritize all product categories currently contained in the website catalogue:

1. Dermal Filler
2. Botulinum Toxin
3. Fat Dissolving / Weight Loss
4. IV Whitening Drip
5. Meso / Skin Booster
6. Topical Anaesthetic

## Product image source

- Product background images must only come from:
  `C:\Users\This PC\Downloads\SOWENA BEAUTY GLOBAL\ẢNH WEB SẢN PHẨM\`
- Search this folder recursively, including category subfolders.
- Copy approved images into `assets/products/` before referencing them in HTML, metadata, or blog cards.
- Do not use web image search, hotlinked images, manufacturer website images, third-party distributor images, Telegram images, or generated images as product background images unless the user first supplies/approves them and they are saved into the approved source folder.
- If no matching image exists in the approved source folder, skip the product and mark the queue note as `Needs approved product background image`.

## Publishing cadence

- Frequency: 1 blog article per day
- Planning rule: keep the next 7 days drafted or scheduled in advance
- Time: 8:00 PM Vietnam time
- Timezone: Asia/Ho_Chi_Minh
- Ordering rule: publish products with available product media first, following the website catalogue category order

## Conversion goal

Every article should guide readers toward:

- reviewing the product catalogue
- understanding the relevant product category
- sending a WhatsApp quotation request

## Offer

Use the current website offer where relevant:

- Code: SOWENA10
- Discount: 10%

## Keyword rule

Use real keyword volume data when available:

1. Google Search Console export
2. Google Keyword Planner export
3. Semrush/Ahrefs export
4. Manual keyword intake sheet

If volume data is not available, use the catalogue-driven content plan and mark each topic as `Needs keyword volume validation`.

- medical claims

- exaggerated product availability statements
