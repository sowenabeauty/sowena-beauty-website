# What I Need From You

To run SEO content properly, please provide these items.

## Required

1. Target market:
   - Vietnam
   - Korea
   - Global
   - US
   - EU
   - Other

2. Main article language:
   - English
   - Vietnamese
   - Bilingual

3. Keyword data:
   - Google Keyword Planner CSV, or
   - Google Search Console CSV, or
   - Semrush/Ahrefs export, or
   - Fill `keyword-intake-template.csv`

4. Product priority list:
   - Dermal filler
   - Botulinum toxin
   - Skinbooster
   - Skincare
   - Wellness
   - Other

5. Compliance rules:
   - Product names allowed
   - Product names to avoid
   - Claims to avoid

## Optional but helpful

1. Competitor websites.
2. Existing customer questions.
3. Top products by profit or sales priority.
4. Countries you can serve.
5. Whether you want 1, 2, or 3 blog posts per week.
6. Google Search Console access or CSV export.
7. Google Keyword Planner export.

## Do not send

Do not send API keys directly in chat.

If OpenAI API automation is needed later, use environment variables:

```text
OPENAI_API_KEY=your_key_here
```
